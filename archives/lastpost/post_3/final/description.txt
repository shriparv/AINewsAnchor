📰 New Nginx Exploit
👉 A critical heap buffer overflow vulnerability, CVE-2026-42945, has been discovered in NGINX's ngx_http_rewrite_module, allowing unauthenticated remote code execution. The flaw stems from a mismatch in buffer size calculation during URI rewriting, leading to exploitable memory corruption. Three additional memory corruption issues were also identified. The vulnerability was autonomously detected by depthfirst's security analysis system.

📰 I knew Linux PCs would get a free pass from California's controversial age-verification law for operating systems
👉 California lawmakers are introducing an amendment to exempt open-source operating systems from the state's Digital Age Assurance Act, which requires age verification during setup. The exemption applies to Linux distributions like Ubuntu, Fedora, and Debian, among others, sparing them from mandatory age checks scheduled to begin January 1, 2027. The amendment defines exempt systems as those distributed under licenses allowing unrestricted copying, redistribution, and modification. This change addresses enforcement challenges previously cited by critics who noted the difficulty of implementing age verification on decentralized, open-source platforms.
