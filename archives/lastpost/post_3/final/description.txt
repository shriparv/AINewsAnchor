📰 Shai-Hulud malware worms Red Hat npm package versions downloaded 80K times a week
👉 Security researchers discovered that dozens of Red Hat npm package releases were infected with the Mini Shai-Hulud worm, a supply chain attack traced to a compromised Red Hat employee GitHub account, affecting packages downloaded 80,000 times weekly. The malware uses preinstall hooks to steal GitHub Actions secrets and npm tokens, with 95 compromised versions identified so far.
