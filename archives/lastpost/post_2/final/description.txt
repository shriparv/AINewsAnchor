📰 Proxmox Virtual Environment Officially Runs on ARM64, But Your Raspberry Pi Isn't Supported Yet
👉 Proxmox Virtual Environment (VE) now officially supports ARM64 architecture, with new images following the same codebase and release lifecycle as x86-64. However, currently, only NVIDIA's Grace and Vera platforms are officially supported, with other ARM-based devices like Raspberry Pi not yet supported.

📰 Show HN: Proxmox -> Share your host's Bluetooth with a VM over the network
