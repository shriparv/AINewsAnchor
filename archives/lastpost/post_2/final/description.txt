📰 streamflow-pulse-client added to PyPI
👉 The streamflow-pulse-client Python SDK has been officially released on PyPI, providing a lightweight, Pythonic interface for interacting with the Pulse AI Agent Platform. It supports context-manager usage, typed exceptions, and attribute-style resource access, and is built with a single dependency on httpx. The client aligns with the Pulse OpenAPI 3.1 spec, ensuring endpoint consistency, and an async version is planned for release in v3.0. Users can install it via pip and requires Python 3.10 or higher.

📰 Made a Tool to Streams Changes from Microsoft SQL Server to Apache Kafka
👉 Athena is a lightweight Change Data Capture (CDC) tool built in Golang that streams database changes from Microsoft SQL Server to Apache Kafka. It simplifies CDC setup by automatically managing configurations and publishing all table changes to a single Kafka topic in an easy-to-process format. Unlike Debezium, Athena requires pre-created Kafka topics and ignores existing data, capturing only new changes. The tool supports SASL-authenticated Kafka brokers and offers straightforward installation through pre-compiled binaries.

📰 How Buildkite Operates Test Analytics at Massive Scale with Amazon MSK and Amazon Managed Service for Apache Flink
👉 Buildkite leverages Amazon MSK and Amazon Managed Service for Apache Flink to power its Test Engine analytics platform, processing over 50 billion requests monthly. The system provides real-time test analytics across thousands of builds for major companies like Slack, Reddit, and Airbnb. Test Engine aggregates results, identifies flaky tests, and supports parallel execution with detailed metadata tagging.
