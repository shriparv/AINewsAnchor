📰 Control AirPods & Galaxy Buds on Ubuntu with ‘BudsLink’
👉 BudsLink is a new Linux app that enables desktop control of Bluetooth earbuds from Apple, Samsung, Sony, and Nothing, offering features like battery level monitoring, noise cancellation, and ambient sound modes directly on Ubuntu without requiring mobile apps. The GTK4/libadwaita application communicates with devices over L2CAP and RFCOMM sockets through BlueZ, providing broader hardware support than similar tools like LibrePods.

📰 Ubuntu and Ubuntu Pro on Azure Cobalt 200 VMs
👉 Microsoft announces preview of Azure Cobalt 200 VMs with second-generation Arm silicon, featuring day-one support for Ubuntu and Ubuntu Pro with seamless deployment, long-term security maintenance, and Kernel Livepatch capabilities.

📰 KDE Plasma 6.7 released
👉 KDE Plasma 6.7 introduces independent per-screen virtual desktops, a feature requested for over two decades, alongside a revived classic theme, HDR and ICC profile support, and performance improvements including Intel GPU enhancements. The release is dedicated to longtime KDE supporter Eric Laffoon and will be available to KDE Neon, Arch, and Kubuntu users in the coming days.

📰 1.38 Millimeter Microcontroller
👉 Texas Instruments' MSPM0C110x microcontrollers are ultra-low-power 32-bit MCUs based on the Arm Cortex-M0 core, featuring up to 24MHz performance, 16KB flash memory, 1KB SRAM, and integrated analog peripherals including a 12-bit ADC and temperature sensor. Designed for extended battery life, these cost-optimized MCUs support communication protocols like UART, SPI, and I2C, and operate across a wide temperature range from -40C to 125C.

📰 Ubuntu To Ship Newer AMD ROCm Updates Via SRUs
👉 Canonical will ship newer AMD ROCm updates via stable release updates (SRUs) for Ubuntu 26.04 LTS, starting with ROCm 7.2, to provide timely support for AMD GPUs and new features without requiring a full Ubuntu release upgrade.
